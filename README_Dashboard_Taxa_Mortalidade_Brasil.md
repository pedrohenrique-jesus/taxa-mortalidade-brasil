# Dashboard --- Taxa de Mortalidade no Brasil

Dashboard interativo desenvolvido no Looker Studio para explorar a
evolução da mortalidade no Brasil entre 1996 e 2019, analisando causas
de óbito, distribuição geográfica e perfil demográfico.

📊 **[Acessar o
Dashboard](https://datastudio.google.com/u/0/reporting/a75f25a1-5983-4c63-b6fc-42275595ca9b/page/ETY9F)**

**Tecnologia:** Google Looker Studio.
